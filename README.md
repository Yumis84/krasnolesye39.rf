# Краснолесье · Cinematic Experience V3

Десятисекундное приглашение в атмосферу Роминтской пущи. Это статический сайт без сборки и production-зависимостей.

## Сценарий

- 0–3,3 с: пробуждение леса.
- 3,3–6,4 с: Краснолесье.
- 6,4–10 с: приглашение продолжить путешествие.
- Через 10 секунд: панель выбора направления без автоматического перехода.

Панель предлагает две обычные ссылки:

- «Открыть Виштынецкий сайт» — https://vishtynets.ru/
- «Гостевой дом» — https://yumis84.github.io/guest-house-map/

Ссылка «Выбрать направление» в шапке открывает выбор немедленно, в том числе до запуска заставки. Обе ссылки доступны с клавиатуры и на сенсорных экранах. При отключённом JavaScript они также показаны сразу. Внешняя страница открывается только после явного выбора посетителя.

Кнопка паузы останавливает анимацию, таймер и звук; заставку можно повторить. При `prefers-reduced-motion` используется статичная композиция с возможностью отдельно включить анимацию. Синтезированный звук запускается только после нажатия кнопки входа.

## Локальный запуск и QA

1. Запустить `python -m http.server 8765 --bind 127.0.0.1`.
2. Открыть http://127.0.0.1:8765/.
3. Выполнить `npm install`, затем `npm test` (по умолчанию используется установленный Microsoft Edge).
4. Если Edge недоступен: `npx playwright install chromium`, затем запустить тест с `QA_BROWSER=chromium`.

Тесты проверяют адаптивные размеры, отсутствие горизонтального переполнения и ошибок JavaScript, финальный выбор без автоматической навигации, точные URL, клавиатурный фокус, паузу/повтор, reduced motion и fallback без JavaScript. Скриншоты и результаты сохраняются в `outputs/`.

## Публикация

Изменение не затрагивает `CNAME`, DNS, настройки Pages, секреты и основной сайт. Публикация выполняется отдельно только после ревью и слияния feature-ветки; этот репозиторий не следует считать развёрнутым только на основании локальных тестов.
