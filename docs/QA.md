# Проверки V3

Автоматический набор `npm test` запускает локальную страницу в Microsoft Edge через Playwright. Для Chromium задайте `QA_BROWSER=chromium`.

Проверяются:

- фазы анимации и финальная панель на 1440×900, 390×844, 320×568 и 844×390;
- отсутствие горизонтального переполнения и ошибок JavaScript;
- появление выбора через 10 секунд без изменения URL;
- немедленное открытие выбора из шапки;
- точные адреса Виштынецкого сайта и гостевого дома;
- последовательный клавиатурный фокус на обеих ссылках;
- пауза, продолжение и повтор заставки;
- статичный режим `prefers-reduced-motion`;
- доступность обеих ссылок без JavaScript;
- отсутствие `location.replace`, `location.assign` и meta refresh.

Скриншоты и JSON-результаты сохраняются в игнорируемой папке `outputs/`. Дополнительный сценарий `node tests/motion.cjs` проверяет движение при повторном запуске и завершение на панели выбора.

Ограничения: Safari, Firefox и физические мобильные устройства требуют отдельной ручной проверки. Тесты не переходят на внешние сайты и не подтверждают публикацию.
